Frequently Asked Technical Questions (FAQ)

Will OneShot #04 overwrite MCP servers I already configured in Claude?

No. OneShot #04 performs a non-destructive JSON merge: it first creates a timestamped .bak backup and then adds or updates the 10 core MCP entries while preserving your existing custom keys.

Why does Claude Desktop show "spawn npx ENOENT" on macOS and how does this fix it?

macOS GUI apps do not inherit your terminal shell PATH (/opt/homebrew/bin or nvm paths). OneShot #04 resolves and injects the exact runtime binary paths so Claude Desktop connects on the first try.

Does this configure both Claude Desktop and Claude Code CLI?

Yes. Both ~/Library/Application Support/Claude/claude_desktop_config.json (or %APPDATA%\Claude on Windows) and ~/.claude.json are configured simultaneously.
