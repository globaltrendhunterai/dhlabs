Will OneShot #11 delete MCP servers I already have in Cursor or Windsurf?

Never. It creates a timestamped .bak backup first and performs a non-destructive merge that preserves every existing custom MCP server key you already configured.

Why does Cursor show a red dot next to MCP servers on macOS and Windows?
