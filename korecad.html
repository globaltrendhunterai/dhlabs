What is KoreCAD Studio? / KoreCAD Studio란 무엇인가요?

KoreCAD Studio is a 100% offline native Rust 2D/3D parametric CAD and DXF/STEP manufacturing takeoff-to-quote platform developed by DH Labs (디에이치랩스 · 사업자등록번호 610-16-92926 · 수석 아키텍트 김동형 / Donghyeong Kim). 설계자와 가공업체는 $19 (19 USD / ₩26,000) 영구 기본판(BASE_CAD)으로 28종 2D 제도·3D 솔리드·10대 산업 포맷 변환과 무료 DXF/STEP/STL 물량 산출을 실행합니다. 업체 자체 단가표와 일괄 B2B 견적서(UTF-8 BOM CSV·HTML·PDF) 출력은 $89 (₩120,000) MOD_CAM_CNC 단품이나 $299 (₩410,000) PRO_ALL 마스터 통합권(단품 합산 $980 대비 69% 절감)으로 10 ms 이내 응답 속도 그대로 즉시 해제합니다.

  • 레이어 0 현장 DXF 정밀 분리 (F49~F50): 모든 선이 레이어 0에 섞인 도면도 선 색상(ACI 62/TrueColor 420)·선 종류(6)·선 굵기(370)·작도 순서로 그룹화해 절단·절곡·제외 공정을 원클릭 보정합니다.
  • 정직한 Class C PDF 차단 원칙: 인쇄 축척 왜곡과 선속성 유실 위험이 큰 PDF 도면은 정밀 견적 입력에서 명시적으로 차단하고 원본 DXF·STEP·STL만 받습니다.
  • 오프라인 공개키 보안 (ECDSA P-256): 256-bit NIST P-256 비대칭 서명 키(KORE2-...)로 폐쇄망 설계 PC에서도 재설치 없이 24시간(3회) 무료 체험과 영구 활성화를 지원합니다.
  • 검증된 엔지니어링 품질: 기하·물리 단위 테스트 715개 이상 및 릴리스 E2E 스모크 39/39 전수 통과, macOS 네이티브 5.0 MB 설치 이미지를 제공합니다.

자주 묻는 질문 (FAQ) — 오프라인 인증과 환불은 어떻게 진행되나요?

Q1. 인터넷이 차단된 사내 폐쇄망 PC에서도 라이선스가 유지되나요?

네. KORE2-<MOD_ID>-<SERIAL>-<SIG> 키는 앱 내부의 NIST P-256 공개키로 완전 오프라인 검증됩니다. 한 번 인증된 모듈은 로컬 볼트(license_state.json과 .kmod.json)에 영구 보관되므로 외부 서버 통신 없이 계속 작동합니다.

Q2. 왜 PDF 도면은 물량 산출 입력에서 차단하나요?

PDF로 인쇄된 도면은 원본 CAD의 선종류·선굵기·실측 단위가 유실되고 인쇄 축척 왜곡이 끼어들어 오견적 위험이 큽니다. KoreCAD Studio는 정직한 Class C 차단 원칙에 따라 PDF 입력을 거부하고 원본 DXF·STEP·STL 파일만 정밀 파싱합니다.

Q3. 결제 후 우리 현장 도면과 맞지 않으면 환불되나요?

네. $19 기본판과 18종 특화 모듈 및 $299 PRO_ALL 통합권 모두 구매일로부터 30일 이내 위약금이나 수수료 없이 100% 환불해 드립니다. 공식 문의는 dhlabs_biz@naver.com으로 접수합니다.
