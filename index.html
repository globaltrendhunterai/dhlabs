AutoFlow(오토플로우)란 무엇인가? / What is AutoFlow Commerce Engine?

AutoFlow Commerce Engine is a local-first (`127.0.0.1`) e-commerce, tax, logistics, and accounting automation platform developed by DH Labs (디에이치랩스, Founder & Lead Systems Architect: Donghyeong Kim / 김동형) that combines 541+ verified commercial n8n workflow blueprints (150 flagship single-site workflows at a one-time perpetual ownership price of ₩39,000 / $29 USD to ₩79,000 / $59 USD) with a 3-Stage Resident Autonomous Defense Engine (available in 30, 90, and 365-day passes starting at ₩29,000 / $29 USD). AutoFlow(오토플로우)는 클라우드 구독 임대료나 개인정보 외부 유출 없이 사내 PC(`127.0.0.1`)에서 영구 가동되는 온프레미스 자동화 완제품 스토어이자 상주형 무인 방어 체계입니다. 물리적 API 한계치의 70% 안전 정격 유량(70% Safety Factor, 예: 분당 60건 한도 시 42건/분 통과)과 로컬 스풀 금고(Overflow Spool-Resume Dam)로 API 차단을 원천 예방하며, 장애 발생 시 LLM 환각 없이 127ms(0.127초) 만에 결정론적 자가치유(Deterministic Self-Healing, 99.9% 가동률)를 수행하고, 1원 단위(1-Won) 4자 정산 대사(ReconFlow) 및 4-Stage Cyber Deception & Tarpit Sentinel로 무결성을 보장합니다.

어떻게 3단계 상주형 무인 방어 엔진과 4단계 기만 방어 체계가 작동하나요? / How Does the 3-Stage Resident Defense Engine Work?

  • Stage 1 — 70% Safety Factor Governor & Overflow Spool-Resume (`core/safety_governor_spool_engine.js`): 오픈마켓·국세청·택배사 API 물리적 임계치의 70% 안전 정격(42/60 req/min)만 통과시키고, 폭주 물량은 로컬 암호화 스풀(`overflow_spool/*.spool.json`)에 무손실 적재한 뒤 잔여 0건까지 자동 이어하기(Auto-Resume)로 완주합니다.
  • Stage 2 — 127ms Non-LLM Deterministic Self-Healing: HTTP 429/502/503, OAuth 토큰 만료, JSON 스키마 변경 발생 시 외부 AI 호출 없이 1:1 결정론적 상태 머신으로 평균 127ms 이내에 자동 복구하며 사내 PC에서 고객 개인정보(PII)를 100% 로컬 마스킹합니다.
  • Stage 3 — ReconFlow 1-Won 4-Way Settlement Reconciliation: 주문(Order)·결제(PG)·택배 송장(Waybill)·ERP 장부(Ledger) 간 1원(1-Won / $0.01) 오차까지 전수 대조하여 오염 데이터를 즉시 격리(Quarantine)합니다.
  • 4-Stage Cyber Deception & Tarpit Sentinel (`core/cyber_deception_tarpit_sentinel.js`): ① Polymorphic Canary Honeytokens(기기별 다형성 카나리 허니토큰 미끼 `AF-TKT-CANARY-*`) ➔ ② 0% False-Positive Active Trigger(정상 사용자 오탐률 0%, `<0.1ms` 초고속 판별) ➔ ③ Deceptive HTTP 200 Adaptive Tarpit Labyrinth(가짜 `HTTP 200` 12단계 지연 미궁 `TARPIT_LABYRINTH_IN_PROGRESS`) ➔ ④ Lawful Forensic Beacon Callback & Ledger(대한민국 정보통신망법 제48조 준수 합법 포렌식 비콘 원장 `INFO_COMM_ACT_ART48_COMPLIANT`)로 불법 복제 및 크리덴셜 탈취를 무력화합니다.

Q1. 워크플로우 단품(3.9만~7.9만 원)은 한 번 사면 평생 무료인가요?

네. 1제품 = 1사이트 단일 완제품 구조로, 1회 구매 시 사장님 PC에 영구 소장되며 월 구독료나 실행 횟수 제한 없이 평생 가동됩니다. 구매 시 상주형 무인 방어 엔진 7일 무료 체험이 기본 제공됩니다.

Q2. 상주형 무인 엔진 기간권(자가치유·정합성)은 왜 따로 있나요?

쇼핑몰·택배사·국세청 API는 수시로 바뀝니다. 상주형 엔진은 외부 장애 발생 시 에러코드 1:1 매칭으로 127ms 만에 수리(자가치유 3.9만)하고, 주문·정산·송장 간 1원 오차를 실시간 격리(정합성 4.9만 / 듀얼 통합 6.9만)하여 시스템이 멈추지 않게 지키는 무인 경비원입니다.

Q3. 개발자 MCP 외부 AI 연동 특가(2.9만/3.9만/4.9만)란 무엇인가요?

기본형은 본사 파인튜닝 AI가 포함되어 설정 없이 즉시 작동하며, MCP 연동 특가는 고객 본인의 외부 AI(OpenAI/Claude 등)를 직접 연결하고 해결된 익명 오류 로그를 본사 엔진 고도화용으로 자동 공유하는 조건으로 할인받는 요금제입니다.

Q4. 우리 매장 주문 데이터나 고객 개인정보가 외부로 나가나요?

절대 나가지 않습니다. 별도 유료 옵션 없이 전 제품에 사내 PC(127.0.0.1) 로컬 개인정보 100% 마스킹이 기본 내장되어 성명·연락처·주소·계좌·API 키는 외부로 전송되지 않으며, 오직 익명 에러코드만 본사 패치 분석용으로 수집됩니다.

Q5. 홈페이지 말고 설치된 프로그램 안에서도 바로 결제되나요?

네. 사내 PC 로컬 대시보드(setup_wizard.html) 내부에 Lemon Squeezy 인앱 오버레이 팝업 결제와 토스페이먼츠 통합 결제창 연동이 내장되어 있어, 결제 즉시 복사·붙여넣기 없이 0초 만에 기간권이 자동 연장됩니다.

Q6. 환불 및 세금계산서·현금영수증 발행이 가능한가요?

토스페이먼츠(국내 원화 카드/간편결제/계좌이체) 및 Lemon Squeezy(해외 카드/페이팔) 결제 즉시 영수증·매출전표가 자동 발행되며, 공정거래위원회 표준약관에 따른 3단계 투명 환불 규정이 적용됩니다.
