자주 묻는 질문 (FAQ) — 설치 방법과 호환 환경이 궁금하신가요?

Q1. 크롬 웹스토어를 거치지 않고도 바로 설치할 수 있나요?

네. 구매 즉시 수령하는 gridpin-customer-bundle-v1.0.0.zip 압축 해제 후 크롬 chrome://extensions에서 '개발자 모드'를 켜고 '압축해제된 확장 프로그램을 로드합니다'로 extension/ 폴더를 선택하면 60초 안에 활성화됩니다.

Q2. 로컬 코드 파일에 직접 덮어쓰다가 원본이 손상되지 않나요?

로컬 브리지(node cli/bridge-server.mjs, 127.0.0.1:3741)는 패치를 반영하기 직전에 반드시 .gridpin_backups/ 폴더에 *.bak 스냅샷을 생성합니다. 또한 작업 프로젝트 폴더 바깥 경로(.env, ../ 등) 접근은 HTTP 403으로 원천 차단됩니다.

Q3. GridPin으로 수정·생성한 UI 코드의 저작권은 누구에게 있나요?

100% 구매 고객 소유입니다. 생성한 React, SwiftUI, Flutter, CSS 코드는 상용 SaaS 및 외주 프로젝트에 제한 없이 배포할 수 있습니다.
