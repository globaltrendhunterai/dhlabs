사내 데이터 유실 방어 4대 기술 원칙

  1. 0초 무설정 직결 파이프 (Zero-Config Direct Pipe): 워크플로우 실행 즉시 사내 로컬 원장 메모리 버퍼와 Json 원장에 동시 반영되어 외부 클라우드 연동 대기 지연이 발생하지 않습니다.
  2. 무충돌 동시성 정렬 (Non-Destructive Deep Merge): 541개 이상의 n8n 블루프린트가 동일 시트에 동시 쓰기를 요청해도 order_dedup_sentinel 뮤텍스가 단조 증가 시퀀스 락을 발급하여 데이터 유실을 방지합니다.
  3. 양방향 인터랙티브 제어 셀 (Bidirectional Action Cell): 데이터 열람에 그치지 않고, 셀 내부의 승인 버튼 클릭 시 n8n 웹훅 엔드포인트를 호출하여 즉시 다음 비즈니스 프로세스를 구동합니다.
  4. UTF-8 BOM 지원 엑셀 완벽 호환 (.csv & .xlsx): 한글 깨짐 없는 표준 UTF-8 BOM 인코딩으로 마이크로소프트 엑셀, 한컴오피스, 네이버 오피스에서 더블클릭 즉시 열립니다.

자주 묻는 질문 (FAQ)

Q1. 기존에 쓰던 회사 엑셀 서식이나 구글 스프레드시트와 어떻게 연동되나요?

기존 엑셀 파일(.csv)을 상단 [기존 엑셀 드래그 앤 드롭 가져오기] 버튼으로 올리면 1초 만에 5대 부서 양식으로 자동 재구조화됩니다. 또한 [엑셀 호환 내보내기] 버튼으로 언제든 원본 엑셀로 내보낼 수 있습니다.

Q2. 541개 워크플로우가 동시 가동되어도 사내 PC가 느려지지 않나요?

네, 실측 테스트 결과 541개 블루프린트 동시 도킹 시 메모리 델타는 단 +7.73MB에 불과합니다. 유휴 상태에서는 0MB 상주 대기(DORMANT_STANDBY)를 유지하므로 저사양 PC에서도 가볍게 작동합니다.

Q3. 양방향 제어 셀의 버튼을 누르면 어떤 보안 검증이 이루어지나요?

승인 버튼 클릭 즉시 SHA-256 감사 해시가 생성되고 상태가 EXECUTED_LOCKED로 잠겨 중복 실행이나 위변조가 차단됩니다. 모든 실행 내역은 사내 PC data/smartgrid_ledger_state.json에 안전하게 보존됩니다.
