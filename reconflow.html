ReconFlow 1원 단위 4자 정산 대사 엔진(ReconFlow Financial Settlement Shield)은 쇼핑몰 실주문(Order), PG사 실결제(PG Settlement), 택배 송장(Courier Waybill), ERP 회계 원장(Accounting Ledger) 4자 데이터를 1원(1 KRW / $0.01) 단위 오차까지 전수 교차 검증하여 결제 누락과 정산 손실을 0원으로 차단하는 엔터프라이즈 정합성 엔진입니다. 오차 발생 시 비파괴 로컬 격리 큐(DLQ)에 안전 보관하며, 127ms 자가치유 및 70% 안전 유량 스풀(42/60)과 함께 ₩49,000/$39 기간권(개발자 MCP 연동 시 ₩39,000/$29)으로 제공됩니다.

  • Stage 1 — 70% Safety Factor Governor & Overflow Spool-Resume (core/safety_governor_spool_engine.js): 오픈마켓·국세청·택배사 API 물리적 임계치의 70% 안전 정격(42/60 req/min)만 통과시키고, 폭주 물량은 로컬 암호화 스풀(overflow_spool/*.spool.json)에 무손실 적재한 뒤 잔여 0건까지 자동 이어하기(Auto-Resume)로 완주합니다.
  • Stage 2 — 127ms Non-LLM Deterministic Self-Healing: HTTP 429/502/503, OAuth 토큰 만료, JSON 스키마 변경 발생 시 외부 AI 호출 없이 1:1 결정론적 상태 머신으로 평균 127ms 이내에 자동 복구하며 사내 PC에서 고객 개인정보(PII)를 100% 로컬 마스킹합니다.
